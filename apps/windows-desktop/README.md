# LinTVPlus Windows

加载 https://tv.987951.xyz 的独立 Windows 客户端。

- 默认 Ctrl+Alt+H 隐藏或恢复窗口，可在“LinTVPlus → 设置”中重新录制。
- 隐藏时暂停音视频并移除任务栏图标，托盘可以恢复窗口或退出。
- 支持 20%～100% 透明度、常驻隐藏任务栏图标、鼠标移出自动隐藏。
- 鼠标移出功能在鼠标进入窗口后才生效，避免快捷键恢复后立刻再次隐藏。
- 设置保存在 Electron 用户数据目录的 settings.json，登录信息由独立浏览器会话保存。

在此目录执行 npm ci、npm test、npm run dist，产物位于 dist/。
桌面壳加载线上网页，网站更新不需要重新打包。窗口功能更新需要下载新版 EXE。
安装版支持启动及每 15 分钟检查更新，也可通过菜单手动检查；下载后确认重启安装。
免安装版发现更新后打开新版下载页。隐藏窗口期间不弹出更新提示。
Windows 更新源使用独立 windows-latest 发布，不会改变 APK 的 latest 更新地址。
当前没有 Windows 代码签名证书。
